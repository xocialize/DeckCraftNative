DeckCraftNative 0.1.3 fixes the colours of VP8 videos and of VP9 videos smaller than HD. It is still an early preview.

**Requires** macOS 26 or later on Apple silicon. Open the DMG and drag DeckCraftNative to Applications, replacing the older version. The app is signed with a Developer ID and notarized by Apple. If you run 0.1.0, 0.1.1 or 0.1.2, Help › Check for Updates… offers this release.

## What's new
- **VP8 and VP9 colours match DeckCraft.** VP8 videos, and VP9 videos of 576 lines or fewer that carry no colour information, now use the BT.601 colour standard, as DeckCraft and ffmpeg do. Earlier versions used BT.709 for them, which was slightly off. HD VP9 videos and videos that say which standard they use are unchanged. The fix is in [vpx-swift 0.3.1](https://github.com/xocialize/vpx-swift).

## Known limitations
- **Video:** AV1 needs an M3 or later.
- **Language:** English only.
- **Spotlight:** it doesn't index the text of `.deckcraft` files yet.
- **Quick Look:** for `.pptx` files it shows macOS's own Office preview.
- **Not supported:** legacy `.ppt` files and password-protected `.pptx` files.

The full list is in [EVALUATION.md](https://github.com/xocialize/DeckCraftNative/blob/main/EVALUATION.md).
