DeckCraftNative 0.1.7 opens and saves password-protected PowerPoint files. It is still an early preview.

**Requires** macOS 26 or later on Apple silicon. Open the DMG and drag DeckCraftNative to Applications, replacing the older version. The app is signed with a Developer ID and notarized by Apple. If you run 0.1.0 to 0.1.6, Help › Check for Updates… offers this release.

## New
- **Opening password-protected presentations.** A `.pptx` saved with a password asks for it before it opens, as PowerPoint does, and asks again if the password is wrong. Files protected by PowerPoint 2007 and later open.
- **Saving with a password.** File › Passwords… (or Review › Protect Presentation) sets a password to open, which encrypts the presentation when it is saved as a PowerPoint file, and a password to modify. Each password is typed twice. A presentation opened with a password keeps it when you save.
- **Password to modify.** A presentation with a password to modify asks for it when it opens. Without it, choose Read Only: the presentation opens as a copy you can edit and save under another name.
- **Good to know:**
  - The `.deckcraft` format can't keep a password, so a protected presentation saved as `.deckcraft` isn't protected. DeckCraftNative says so when it happens.
  - AutoRecover doesn't keep copies of password-protected presentations, so they are never written to disk without their password.
  - Exports (PDF, pictures) are never password-protected.

## For scripts
- **Opening:** `file.open` and `file.openBytes` take `password` and `modifyPassword`, and so does the control channel's `app.open`. A missing or wrong password comes back as an error that says which. Nothing a script opens waits for a person.
- **Setting:** `file.passwords {password?, modifyPassword?}` sets the passwords, and `null` removes one.
- **dccli:** reads the password of a protected file from the `DCCLI_PASSWORD` environment variable.
- **Where passwords go:** they are kept only in memory, with the open presentation. They never appear in command replies or the command journal.

## Known limitations
- **Not supported:**
  - legacy `.ppt` files;
  - files protected with rights management (IRM) or a third-party encryption module.
- **Video:** AV1 needs an M3 or later.
- **Language:** English only.
- **Spotlight:** its search panel finds `.deckcraft` files by name, not by the words inside them; ask Siri for those. `.pptx` files are indexed by macOS itself.
- **Quick Look:** for `.pptx` files it shows macOS's own Office preview.
