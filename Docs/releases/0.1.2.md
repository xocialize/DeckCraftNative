DeckCraftNative 0.1.2 is a polish release: Shortcuts that work on files can run without opening a window, and three layout problems are fixed. It is still an early preview.

**Requires** macOS 26 or later on Apple silicon. Open the DMG and drag DeckCraftNative to Applications, replacing the older version. The app is signed with a Developer ID and notarized by Apple. If you run 0.1.0 or 0.1.1, Help › Check for Updates… offers this release.

## What's new
- **Shortcuts in the background.** Export Presentation, Get Outline and Get Slide Count now run in a background App Intents extension. macOS can use them on a file without opening DeckCraftNative or an empty window. The other actions (Open, New Presentation, Add Slide, Start Slide Show, Run DeckCraft Command) work with the app, as before.
- **Theme Colors dialog.** The twelve theme colours are laid out in aligned columns, and every colour well stays inside the dialog.
- **Inspector choices.** Choices like Review's Comments, Thesaurus and Revisions stay segmented where they fit, and become a pop-up menu where they don't, so they no longer run past the inspector's edge.
- **Status bar.** In a narrow window it drops the zoom slider, then the view buttons, and always keeps the zoom percentage and Fit, instead of clipping the zoom controls.
- **Colour names** in the colour menus and Theme Colors (Accent 1, Lighter 40%, Dark Blue…) can now be translated, like the rest of the interface.

## Known limitations
- **VP8 and VP9 colours:** VP8 videos, and VP9 videos smaller than HD that carry no colour information, show slightly different colours than DeckCraft or ffmpeg would.
- **Video:** AV1 needs an M3 or later.
- **Language:** English only.
- **Spotlight:** it doesn't index the text of `.deckcraft` files yet.
- **Quick Look:** for `.pptx` files it shows macOS's own Office preview.
- **Not supported:** legacy `.ppt` files and password-protected `.pptx` files.

The full list is in [EVALUATION.md](https://github.com/xocialize/DeckCraftNative/blob/main/EVALUATION.md).
