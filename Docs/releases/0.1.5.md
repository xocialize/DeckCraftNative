DeckCraftNative 0.1.5 fixes bugs in 0.1.4's ribbon that turned up when it was used from the keyboard. It is still an early preview.

**Requires** macOS 26 or later on Apple silicon. Open the DMG and drag DeckCraftNative to Applications, replacing the older version. The app is signed with a Developer ID and notarized by Apple. If you run 0.1.0 to 0.1.4, Help › Check for Updates… offers this release.

## Fixed
- **The slide pulsing.** At some window sizes, with always-visible scroll bars, a fitted slide switched between two zoom levels over and over.
- **A blurred band over the slide.** A window that opened with the ribbon blurred the top of the slide just under the ribbon. Switching layouts cleared it.
- **The ribbon from the keyboard.** With Full Keyboard Access on, fn+F6 or View › Move Focus to the Ribbon moves the keyboard to the ribbon. There:
  - a ring now shows which command has the keyboard;
  - the arrow keys no longer get stuck on a command with a menu, such as Paste;
  - the arrow keys step past commands that are turned off, and past groups where every command is off, instead of going back to the start of the group;
  - ⌥↓ opens the menu of a command such as Paste, as Space and Return already did.
- **Slide thumbnails too far apart.** With always-visible scroll bars, the thumbnails beside the slide had extra space between them until the layout was switched.

## Known limitations
- **Video:** AV1 needs an M3 or later.
- **Language:** English only.
- **Spotlight:** it doesn't index the text of `.deckcraft` files yet.
- **Quick Look:** for `.pptx` files it shows macOS's own Office preview.
- **Not supported:** legacy `.ppt` files and password-protected `.pptx` files.

The full list is in [EVALUATION.md](https://github.com/xocialize/DeckCraftNative/blob/main/EVALUATION.md).
