DeckCraftNative 0.1.1 plays VP9 and VP8 video. It is still an early preview.

**Requires** macOS 26 or later on Apple silicon. Open the DMG and drag DeckCraftNative to Applications, replacing 0.1.0. The app is signed with a Developer ID and notarized by Apple. If you run 0.1.0, Help › Check for Updates… offers this release.

## What's new
- **VP9 and VP8 video plays.** WebM and Matroska videos with these codecs now play in the editor and the slide show, and get a real poster frame when inserted. In 0.1.0 they showed "can't be played". Decoding uses libvpx, through [vpx-swift](https://github.com/xocialize/vpx-swift); macOS has no decoder for either codec. DeckCraft itself doesn't play VP8.
- **Up to date with DeckCraft.** The port now follows DeckCraft's latest code (`88c2ceff`). DeckCraft's changes since 0.1.0's base only moved code around, so the app's behaviour is unchanged. `dccli bench` now times PDF export on every run, as DeckCraft's CLI does.
- **Open source licence.** DeckCraftNative's own code is now MIT OR Apache-2.0, like DeckCraft's (`LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`).

## Known limitations
- **VP8 and VP9 colours:** VP8 videos, and VP9 videos smaller than HD that carry no colour information, show slightly different colours than DeckCraft or ffmpeg would. They use the BT.709 colour standard where those use BT.601; the difference is small but visible side by side.
- **Video:** AV1 needs an M3 or later.
- **Language:** English only. The interface is ready for translation.
- **Spotlight:** it doesn't index the text of `.deckcraft` files yet.
- **Quick Look:** for `.pptx` files it shows macOS's own Office preview.
- **Not supported:** legacy `.ppt` files and password-protected `.pptx` files.

The full list is in [EVALUATION.md](https://github.com/xocialize/DeckCraftNative/blob/main/EVALUATION.md).
